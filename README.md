# PHP・MySQL Web開発環境（掲示板アプリ用）

## 概要
PHPとMySQLを用いたWebアプリケーション開発の学習用プロジェクトです。

掲示板アプリケーションの開発を目的として、Dockerを活用したローカル開発環境を構築しました。

## 実装・構築内容
- DockerによるPHP・Apacheの実行環境
- MySQLを使用したデータベース環境
- phpMyAdminによるデータベース管理環境
- PHPの動作確認用ページ

## 使用技術

| 分類 | 技術 |
| --- | --- |
| バックエンド | PHP |
| データベース | MySQL 8.0 |
| Webサーバー | Apache |
| 開発環境 | Docker、Docker Compose |
| DB管理 | phpMyAdmin |
## 開発で学んだこと
Webアプリケーション開発に必要なサーバーとデータベースの構成を学ぶため、Dockerを用いて複数のサービスを連携させる開発環境を構築しました。

PHPとMySQLの接続や、コンテナ上でのWebアプリケーション実行について理解を深めました。
